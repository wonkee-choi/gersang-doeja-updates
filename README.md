# 거상이되자

Windows용 거상 보조 프로그램입니다. 설치 파일에는 앱과 백그라운드 구성요소, 영상 분석 런타임, **연못이무기(水)·사인 초기 사냥 설정과 이름 표본**이 포함됩니다.

**[최신 설치 파일 다운로드](https://github.com/wonkee-choi/gersang-doeja-updates/releases/latest)**

Releases의 `GersangDoeja-Setup-…-x64.exe`를 내려받으세요. `update.json`은 앱의 업데이트 확인용 파일이므로 직접 실행하거나 설치할 필요가 없습니다. GitHub가 표시하는 `Source code` 압축 파일은 설치 파일이 아닙니다.

## 설치 조건

- Windows 10 2004(빌드 19041) 이상 또는 Windows 11, x64 PC.
- 별도로 설치된 공식 거상 게임 클라이언트.
- 설치와 백그라운드 게임 실행에 필요한 관리자 권한.
- 설치 파일 다운로드·필수 구성요소 준비·업데이트 확인에 사용할 인터넷 연결.

Python·OpenCV·NumPy와 백그라운드 구성요소는 앱에 포함됩니다. 사용자가 개발 도구나 시스템 Python을 별도로 설치할 필요가 없습니다. 앱은 시스템 Python이나 `PATH`를 변경하지 않습니다.

Microsoft WebView2가 없으면 설치 프로그램이 공식 서버에서 받아 설치합니다. Npcap이 없으면 공식 서버에서 받은 **Npcap 설치 창이 열리며, 사용자가 사용권과 옵션을 확인하고 설치를 완료해야 합니다.** Npcap 설치 파일은 이 설치 파일에 포함되지 않습니다.

## 새 PC에 처음 설치하기

1. 위 다운로드 페이지에서 최신 Setup 실행 파일을 내려받아 실행합니다.
2. 거상이되자 전용 설치 폴더를 선택합니다. C·D 등 드라이브는 선택할 수 있습니다. **거상 게임 폴더 안에는 설치하지 마세요.**
3. 필수 구성요소 설치가 끝날 때까지 기다립니다. Npcap 설치 창이 열리면 직접 완료합니다.
4. 설치 완료 후 바탕화면 또는 시작 메뉴에서 **거상이되자**를 실행합니다.
5. **클라이언트 → 클라이언트 관리**에서 사용할 게임 설치 폴더를 등록합니다. `Run.exe`와 `Gersang.exe`가 있는 폴더를 선택합니다.
6. **계정 관리**에서 사용할 계정을 등록하고 실행 슬롯에 연결합니다. 로그인·OTP 등 추가 인증·서버 선택은 게임 화면에서 직접 완료합니다.

게임 폴더 이름이 반드시 `Gersang2`일 필요는 없습니다. 등록한 클라이언트와 선택한 실행 슬롯을 사용하며, 게임·백그라운드 구성요소 경로를 특정 드라이브로 고정하지 않습니다.

## 백그라운드 사냥 시작하기

1. 클라이언트 화면의 해당 슬롯에서 **백그라운드 사냥용 실행**을 누릅니다. 이 버튼은 패킷 수집도 먼저 준비합니다.
2. 게임 접속 후 필드에서 대기합니다.
3. **사냥 보조 → 상태·창 새로고침**을 누르고, 방금 실행한 게임 창을 선택합니다.
4. **사냥 대상 저장·전환**에서 현재 몬스터와 같은 대상을 선택하고 **선택 대상 불러오기**를 누릅니다. 대상별 숫자·사용 여부·이름 표본이 함께 복원됩니다.
5. 처음에는 게임 화면을 **1280×960**, Windows 배율을 **100%**로 맞추는 것을 권장합니다. 초기 데이터의 기준 환경이며, 전투 미니맵은 **검은 바탕·유닛 점 표시**로 맞춥니다.
6. 거상이되자나 워드 등 다른 앱을 앞으로 둔 상태에서 **백그라운드 사냥 시작**을 누릅니다. 게임은 최소화하지 마세요.
7. 중지하려면 **F9** 또는 사냥 보조의 **중지** 버튼을 사용합니다.

**백그라운드 사냥용 실행**은 게임을 실행하는 버튼이고, **백그라운드 사냥 시작**은 자동 입력을 시작하는 버튼입니다. 게임을 앞으로 가져오면 직접 조작으로 판단해 백그라운드 입력을 중지할 수 있습니다.

배율에 따른 가상 포인터 좌표 보정을 포함하지만, 모든 PC·게임 버전·해상도에서 같은 결과를 보장하지는 않습니다. 새 환경에서는 짧게 동작을 확인하세요. 전투 진입 후 4초 안에 Q·E가 시작되지 않거나 위험하면 F9로 중지하고 직접 조작하세요.

## 기존 버전에서 업데이트하기

**0.8.31 이전 버전에는 앱 내 업데이트 기능이 없습니다. 최신 Setup을 한 번 직접 설치해야 합니다.**

1. 안전한 필드에서 사냥을 중지합니다.
2. 거상이되자를 직접 닫습니다. 앱으로 실행한 백그라운드 게임도 함께 종료됩니다.
3. 최신 Setup을 실행하고 **기존 거상이되자 설치 폴더**를 선택합니다. 다른 폴더를 선택하면 기존 설정을 이어서 사용하지 못할 수 있습니다.
4. 설치 완료 후 앱을 실행하고 게임에 다시 접속합니다.

0.8.31부터 앱 시작 시 업데이트를 확인합니다. **설정 → 프로그램 업데이트 → 업데이트 확인**에서도 직접 확인할 수 있습니다. 새 버전이 있으면 **다운로드 후 설치**를 누르고 종료·설치 안내를 확인하세요. 설치 후 앱을 다시 엽니다.

업데이트는 사용자 확인 후 진행합니다. 앱은 내려받은 파일의 배포자 서명·크기·SHA-256을 검증합니다. 업데이트 확인이나 다운로드만으로 게임을 재접속할 필요는 없으며, 실제 설치 시 앱과 연결된 게임이 종료됩니다.

## 설정·개인 데이터 보존

- 계정·사냥 설정·표본은 기존 앱의 `Data`에 보존합니다. 업데이트가 초기 데이터로 기존 파일을 덮어쓰지 않습니다.
- 다른 PC에는 계정을 새로 등록하세요. 비밀번호는 해당 PC의 현재 Windows 사용자용 암호화 저장소에 보관됩니다.
- 설치 파일과 공개 배포 저장소에는 개인 계정·비밀번호·로그인 정보·플레이 화면·패킷 기록·앱 소스를 올리지 않습니다.
- 앱 제거 후에도 `Data`는 보존됩니다. 설정을 직접 옮기거나 정리하기 전에는 앱을 닫고 별도로 백업하세요.
- 게임 클라이언트 파일은 배포하지 않으며, 설치·업데이트 과정에서 게임 폴더 파일을 변경하지 않습니다.

## 문제가 있을 때

| 증상 | 먼저 확인할 내용 |
| --- | --- |
| 백그라운드 실행 버튼이 없음 | 유효한 게임 폴더·계정이 해당 실행 슬롯에 연결됐는지 확인합니다. |
| 화면 캡처가 오래됐거나 WGC 오류가 표시됨 | 선택한 게임이 실행 중이고 최소화되지 않았는지 확인합니다. 사냥을 중지하고 게임 창을 새로 선택합니다. |
| 접속 초기 키가 없다고 표시됨 | 먼저 패킷 수집 상태를 확인합니다. 초기 키를 실제로 놓친 경우에만 수집을 켠 채 해당 게임을 한 번 재접속합니다. |
| 다른 앱을 쓰는데 사용자 마우스 입력으로 중지됨 | 일반 사냥 시작 대신 **백그라운드 사냥 시작**을 눌렀는지, 선택 창이 백그라운드 실행한 게임인지 확인합니다. |
| 백그라운드 응답 만료가 반복됨 | 0.8.31 이상인지 확인합니다. 계속 발생하면 중지 사유와 발생 시각, 앱의 진단 기록을 함께 확인해야 합니다. |
| 업데이트 서버에 연결되지 않음 | 인터넷 연결을 확인합니다. 위 공개 다운로드 페이지에서 최신 Setup을 직접 설치할 수도 있습니다. |

자동 검사·설정 보존 설치·공개 서버 다운로드 및 서명 검증은 수행했습니다. 실제 새 PC의 장시간 사냥은 환경별 확인이 필요합니다.
