# 거상이되자 업데이트

Windows x64 설치 파일과 서명된 업데이트 정보를 배포합니다.

[최신 설치 파일 다운로드](https://github.com/wonkee-choi/gersang-doeja-updates/releases/latest)

연못이무기(水)·사인 초기 사냥 설정과 이름 표본이 포함됩니다. 앱 소스·계정·비밀번호·플레이 기록은 배포하지 않습니다.

0.8.31부터 앱 시작 시 업데이트를 확인하며, 설정 → 프로그램 업데이트에서도 확인할 수 있습니다. 설치는 사용자 확인 후 진행하고, 기존 계정·사냥 설정·표본을 보존합니다. 이전 버전은 최신 설치 파일을 한 번 직접 설치해 주세요.

게임 클라이언트 파일은 포함하지 않으며 변경하지 않습니다. 필요한 경우 설치 과정에서 공식 Npcap 설치 창을 직접 완료해 주세요.
